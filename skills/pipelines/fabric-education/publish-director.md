# 面料教育 - Publish Director（发布总监）

## 角色
为各平台生成适配的发布文案和封面图。教育内容的发布风格不同于推广内容——强调"干货"、"避坑"、"经验分享"，而非"好看"、"下单"。

## 输入
- `fabric_edu_brief`（面料事实、pitfalls）
- `note_manifest`（各平台笔记版本）
- `render_report`（如果有视频产出）

## 流程

> **⚠️ 路径规范**：所有相对路径必须带 `projects/{project_name}/` 前缀。

### Step 1: 按平台产出发布文案

#### B站（如果有视频）

| 字段 | 规范 |
|------|------|
| 标题 | ≤80 字，突出面料知识点/避坑价值 |
| 正文 | 300-500 字，前 3 行含核心关键词 |
| 标签 | ≤10 个，如 #面料 #纺织 #避坑 #XX面料 |
| 封面 | 16:9（1920×1080），知识感强 |

标题范式：
- "90% 的人不知道 XX 面料的这个秘密 🤫"
- "面料老手教你 3 步辨别 XX 真假"
- "别再被 XX 面料的宣传骗了！真相是..."

#### 小红书

| 字段 | 规范 |
|------|------|
| 标题 | ≤20 字，含 emoji，有钩子 |
| 正文 | 150-300 字，知识段落 + 个人经验 |
| 话题标签 | 5-8 个 |
| 封面 | 3:4（1080×1440） |

标题范式：
- "🔥 别再被骗了！XX 面料 3 步辨真假"
- "面料行家才知道的 XX 挑选秘籍 ✨"
- "第一次买 XX 面料？记住这 3 点不踩坑"

正文风格：口语化、有温度、体现"行业老手"身份。

#### 公众号

| 字段 | 规范 |
|------|------|
| 标题 | 知识科普风格，有信息量 |
| 摘要 | 一句话概括文章价值 |
| 正文 | 完整长文（可复用 note_manifest.core_article） |

标题范式：
- "如何辨别 XX 面料的真伪？一个面料老手的 3 个实用方法"
- "XX 面料到底值不值得买？拆开揉碎讲给你听"

#### 知乎

| 字段 | 规范 |
|------|------|
| 标题 | 偏问题/科普风格 |
| 正文 | 测评/科普风格，有干货论证 |

标题范式：
- "XX 面料到底是什么档次？内行人告诉你真相"
- "同样叫 XX 面料，价格差 10 倍，区别在哪？"

#### 朋友圈

- ≤150 字
- 开头直接抛出问题/观点
- 中间快速给出价值点
- 结尾引导去小红书/公众号看全文

### Step 2: 封面图生成

通过 `image_selector`（img2img 模式，以面料原图为底图）生成封面：

- 小红书封面：3:4，1080×1440
- B站封面：16:9，1920×1080

封面设计原则：
- 教育感 > 广告感
- 文字清晰可读
- 配底色从面料主色提取
- 无夸张广告语

### Step 3: 产出 publish_copy artifact

遵循 `schemas/artifacts/publish_copy.schema.json` 格式，包含各平台版本。

### Step 4: 合规检查

- 无绝对化用语（第一、最、100% 等）
- 无虚假宣称
- 面料事实与 fabric_edu_brief 一致
- 素材路径全部指向项目内 assets/ 目录
