# 项目上下文：二创解说（ref-remake）

## 领域范围

将一条海外参考视频（通常是 YouTube 解说/科普片）转化为中文竖屏 9:16 二创解说视频：下载分析原片 → 结构借鉴+改写中文脚本 → IndexTTS 克隆配音 → MiniMax 生图（阿黄 + V2 点缀式 + 参考图锚点）→ HyperFrames 合成 → M3 抽帧质检 → 双平台成品包（抖音+小红书）。小红书附带轻量图文笔记变体。脚本闸门人审 + 最终质检人审，发布手动。以单集为主，超长原片可提案拆 2 集。

## 核心术语

### 二创解说

输入一条参考视频，用全新中文表述与本土化案例重新制作的中文竖屏解说视频。与「逐句翻译搬运」和「多来源原创汇编」区分：保留原片的叙事结构与核心观点，全部措辞重写。

### 参考视频

输入源，提供叙事结构与核心观点；不是可复制的成品素材。下载后抽帧做风格/场景密度分析，供改写与视觉设计参考。

### 结构借鉴+改写

前期档位：保留原片叙事结构与核心观点，全部措辞重写 + 本土化案例。操作红线由工单《二创改写红线操作定义》定义（相似度阈值 0.75 红 / 0.45 黄）。

### 阿黄

管线默认角色：米白底点缀式风格中的黄色胶囊小人，画面焦点（占 60%+、居中）。全管线共用同一角色设定。

### V2 点缀式风格

默认视觉风格：米白底 + 阿黄居中焦点 + 1-3 个内容相关必要元素点缀。禁：完整房间家具、场景堆砌、人群、3D/CGI。

### 参考图锚点

用已确认的角色参考图 + 强风格约束提示词调用 MiniMax image-01，提升跨画面角色一致性（实测 75-80%）。锚点图为项目级资产，随管线沉淀。

### 无字底稿

不含任何文字的 AI 生图底稿。中文文字全部由 HyperFrames HTML 层叠加，规避生图模型中文错字。

### 脚本闸门

中文脚本未经人工审批通过前，禁止进入任何重量级资产生成环节（图像、TTS、渲染）。闸门是管线的强制停机点。

### 图文笔记变体

从成片/生成帧中选 6-9 张 + 自动写小红书笔记文案（标题/正文/话题标签），管线轻量内置一键产出；不做重排版。

### 成品包

交付物集合：成片 + 双平台标题/简介/封面图 + 图文笔记 + AI 标识声明。发布由人工手动上传。

### 按内容定长

成片时长由中文内容决定，不强制等于原片时长。IndexTTS 语速约 250 字/分。

### AI 标识

成片**不烧录角标**（保持画面专业）；发布时双平台勾选「AI 生成」声明，平台侧自动叠加角标（《标识办法》2025-09-01，findings/05：创作者侧以勾选声明为主）。双平台正文 AI 声明文案不可省略，流水线内置。
