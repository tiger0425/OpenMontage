# 02 二创改写红线操作定义（定案）

> 工单《二创改写红线操作定义》决议（2026-08-26 人审确认，四项决策全部按推荐采纳）。基线：火柴人线 findings/04 定案；按二创场景（单视频驱动、双平台、有参考视频分析环节）微调，独立成文。

## 1. 允许保留（白名单）

- **核心观点/知识点本身**：公共领域事实与概念可保留（如「损失厌恶」「峰终定律」「身体的健康信号」）。
- **论证骨架**：钩子→论点→案例→反转→结论的段落顺序与节奏结构。
- **案例主题方向**：可保留「用超市定价讲锚定效应」这类主题级描述。

## 2. 必须改（改写义务，全部满足才算合格）

| 项 | 标准 |
|---|---|
| 全部措辞 | 中文重写，禁止逐句对译腔；口播稿与原转录稿逐句对照不得出现「同序同义句」 |
| 案例本地化 | 原案例（美式超市/职场/外国地名）必须替换为中国语境等价物（菜市场/拼多多/职场加班等）；人物名、地名、品牌全换 |
| 文化语境转换 | 玩笑/俚语/宗教政治敏感梗一律弃用或替换为中文互联网通行表达 |
| 数字与引用 | 原片引用的实验/论文保留事实，但表述方式必须重写并注明「有研究显示」级别措辞 |
| 开头钩子 | 必须原创，禁止复刻原片前 15s 的悬念句式 |

## 3. 禁止（红线，触发即打回）

- 原句直译 / 语序微调的同义替换（判定见 §4）；
- 复制原片**专有桥段**：独特的比喻、段子、口头禅、角色设定；
- 复刻原画面构图/分镜（本管线视觉为全新阿黄场景 + 无字底稿，天然隔离；且参考分析产出不进分镜，见 §5）；
- 使用原片出镜者姓名/声音/肖像相关素材；
- 原频道名称、口号、标志性开场白出现在成片中。

## 4. 自查机制（可执行验收）

1. **工具对照**：改写稿 vs 原转录稿做逐句相似度扫描，阈值沿用 **单句相似度 ≥0.75 判红，整篇 ≥0.45 判黄需人工复核**（0.75/0.45 绘图会话已确认沿用）。
2. **实现落点**：新建轻量 n-gram 重合率脚本 + LLM 逐句自查，并入《管线 manifest 与阶段设计定案》执行期清单（不单开工单；repo 现无适用工具，已核实）。
3. **三查抽查**：每集随机抽 5 句人工对照（开头钩子、核心论点句、最长案例句必抽）。
4. **红线清单勾选**：§3 五条逐项勾选，存入 `script_review.md` 与脚本闸门一起人审。
5. **责任链**：LLM 初稿 → 自动相似度扫描 → 人审闸门（脚本闸门同一停机点）→ 通过后解锁 TTS/生图。

## 5. 与参考视频分析的协调

brief 阶段参考视频分析（video-reference-analyst 五维分析 + 风格/场景密度）**只服务于差异化概念与风格迁移参考，产出不进 scene_plan 具体分镜**；脚本中的画面指令禁止逐镜描述原片镜头/构图。分析产出仅作背景参考。

## 6. 双平台合规（通用红线之外的附加节）

- **科普/健康类选题措辞**：规避绝对化断言——禁「治疗」「治愈」「100% 有效」「医学证明」等表述，统一降级为「有研究显示」「有数据表明」级别措辞（参照火柴人线「生活冷知识规避医疗监管」经验）。
- **AI 标识声明必填**：成片**不烧录角标**（保持画面专业）；发布时双平台勾选「AI 生成」声明，平台侧自动叠加角标（《标识办法》2025-09-01，findings/05：创作者侧以勾选声明为主，无需自绘角标）。双平台正文 AI 声明文案不可省略。
- 抖音与小红书的规则差异（如健康内容白名单、医疗类目限制）按平台分别核对填写，不写死为单一条款。

## 7. 与其他工单接口

- 红线挂载于**脚本闸门**（`human_approval_default: true`），与拆集提案合并为同一人工停机点审（见《管线 manifest 与阶段设计定案》）。
- 相似度扫描 JSON（`redline_scan`）为 script 阶段产物，闸门必需附件。
- 升格为「观点级重创作」时另起地图，本文件届时整体作废重写。
