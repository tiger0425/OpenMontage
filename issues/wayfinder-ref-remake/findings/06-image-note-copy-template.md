# 06 图文笔记文案模板（定案）

> 工单《图文笔记文案模板》决议（2026-08-26 人审确认）。前置调研：`findings/05-image-note-platform-specs.md`。

## 定位（用户确认：独立干货型）

图文笔记是**独立内容**，不依赖视频：自成一篇干货图文，视频作为附录引导（末尾一条「看完整视频」链接/引导）。标题/正文/图片共同把选题讲清楚，未看视频的人也能读懂。

## 图片形态（用户确认：原图 + 文字卡片）

**每张图 = 生成原图 + 叠加文字卡片**（要点文字承载在卡片上），构成信息图卡序列，不是裸生成图轮播。

- 选图来源：**生成原图**（非成片抽帧——规避烧录字幕/AI 角标/画质损失；findings/05 抽帧注意点）
- 数量：**6-9 张**（小红书安全区间，上限 18 第三方说法；findings/05）
- 比例：**3:4 竖版（1080×1440）**，9:16 生成原图 → 3:4 裁上下保留中部 75% 高度内容
- 文字卡片承载：**排版层叠加**（HTML/PIL），与「无字底稿 + 后期叠字」原则一致——AI 图内永远无文字，要点文字由排版层渲染后合成到卡片图
- 每张卡片 1 个要点：从脚本知识点/要点提取，1-2 句 + 可选数字强调

## 标题与正文结构（用户确认：钩子 + 要点回顾 + 互动引导）

### 标题（≤20 字，小红书官方限制）
- 独立钩子：从选题提炼，不直接复制视频标题（但可同源）；钩子形态参照视频标题格式（数字/反常识/悬念）

### 正文（≤1000 字，可超千字）
```
[钩子句] 一句话抓住注意力（反常识/数字/悬念）

[要点 1] 与第 1 张卡片对应，1-2 句讲透
[要点 2] 与第 2 张卡片对应，1-2 句讲透
...（3-5 个要点，与所选 6-9 张卡片中的核心几张对应）

[互动引导] 收藏备用 / 评论区聊聊 / 想看完整视频点主页

[AI 声明] 本图文由 AI 辅助生成（固定常量）
```

## 话题标签（用户确认：主题 + 定位 + 长尾 3-6 个）

- 1 个选题主题话题（从标题/选题提取）
- 1 个账号定位话题（如 #阿黄科普，可扩展）
- 1-3 个内容相关长尾话题（从脚本关键词提取）
- 总数 3-6 个（findings/05：建议 3-6，上限 10，过多判营销）

## AI 声明（用户确认：正文固定声明 + 发布勾选）

- 正文末尾固定声明文案：「本图文由 AI 辅助生成」（模板常量，不可省略）
- 发布时双平台勾选「AI 生成」声明（《标识办法》2025-09-01 施行，findings/05：抖音未标最高封号、小红书限流扣流量）
- 平台角标由平台侧叠加，创作者侧以勾选声明为主

## 封面

- 双平台共用一张 **3:4（1080×1440）** 封面（findings/05：两平台均以 3:4 为推荐主流）
- 封面文字/主体放画面中部安全区，上下各留 10-15% 边距
- 封面可复用视频的 3:4 封面图或单独生成

## 执行期落点

- package 阶段产出：`note_manifest`（通用化 schema，见 findings/01）+ 6-9 张卡片图（3:4，原图+文字卡片排版层合成）+ 文案模板填充
- 图文发布为人工手动（与视频一致）
- 若需 1:1 备选：从 3:4 居中裁剪生成

## 留白（以平台发布页实际限制为准）

- 抖音普通图文图片上限（35 张第三方）、文案上限、话题上限；小红书长文上限具体字数、话题官方上限——findings/05 未获权威来源，模板按保守值取用，package 阶段遇平台限制时调整。
