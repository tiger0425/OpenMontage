# 03 分集切分规则细则（提案 v1，待人审）

> 工单《分集切分规则细则》产出。以下为可执行算法定义提案；标 ⚖ 的项需用户拍板。

## 1. 切点算法（LLM 提案 + 人审确认，两段式）

1. **输入**：Whisper 转录（带时间戳）+ 原片元数据（标题/简介/chapter）。
2. **叙事分段（LLM）**：按「钩子 → 论点 → 案例 → 反转/结论」单元切叙事段落，输出候选切点列表（每项含：时间码、段落摘要、悬念强度 0-5）。
3. **切点选择规则**（按序应用）：
   - 优先选**悬念强度 ≥3 的钩子句尾**为切点（前集结尾留钩，后集开头回收）；
   - 切点回退到最近的**静音间隙 >0.8s 或章节边界**（±15s 内），避免句中硬切；
   - 单集目标时长 90–150s；原片 ≤150s 不拆。
4. **人审确认**：切点表渲染成 `split_review.md`（时间码 + 每集一句话梗概），用户确认后才进入脚本闸门。⚖ 默认采用此两段式。

## 2. 每集独立性要求

- 硬性：每集脚本自含「背景一句话 + 本集论点完整闭环」，不依赖前集信息即可看懂；
- 集间衔接模板（固定话术骨架，LLM 填空）：
  - 前集结尾：`"……但这只是上半场，真正的反转在下一集。"`
  - 后集开头：`"上一集说到 {前集论点半句}，接下来才是关键——"`（10s 内完成回收）
- 每集独立标题与封面，不共享上下文才能理解的核心概念需在后集用 ≤2 句重述。

## 3. 边界情况

| 情况 | 处理 |
|---|---|
| 拆后单集 <60s | ⚖ 默认**并回相邻集**（优先并回叙事上承接更强的一侧）；若并回后 >180s 则改为扩写该集钩子补足 |
| 150–170s（略超） | 不拆，允许 ±20s 容差（目标 90–170s 实际区间） |
| >170s 且无强悬念切点 | 按「论点数」均分强制切，切点仍回退静音/章节边界 |
| 原片 <60s | 弃用（低于试点价值）或并入同主题合集，不单独成集 |

## 4. 标题规范

- 格式：`{钩子主标题}｜第N集`；主标题 ≤14 字、不含剧透结论；
- 集标识位置固定放尾部，抖音/小红书搜索权重词前置；
- 系列统一前缀可选（如「心理冷知识」），试点期由账号定位工单《账号定位与频道名候选》定；
- 封面角标：右上角 `EP.N/总集数`（排版层叠加，非生图）。
