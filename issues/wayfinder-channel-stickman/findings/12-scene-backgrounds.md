# 12 场景背景生成设计（非模板）+ 品牌物料模板适配（提案 v1，待人审）

> 工单《minimax 生图适配》范围修正版（2026-08-25 用户拍板：背景按内容逐场景生成，不是模板）。标 ⚖ 需确认。

## 1. 核心原则：背景 = 场景叙事载体

- 每集每个 scene 生成**专属背景图**：画面主体由该 scene 的 narration 决定（例：讲「超市定价」→ 超市货架；讲「身体器官」→ 解剖示意图背景）。
- 火柴人 SVG 叠在背景**前景层**，两者同框共同表达内容；禁止「空白背景 + 孤立火柴人」。
- 背景图内**零文字**（无字底稿铁律），所有中文走排版层。

## 2. 逐场景生成流程（资产阶段内嵌）

```
script.json scenes[] → LLM 背景 prompt 推导 → image_selector(minimax 主/imagen 备) → 背景图 → 合成层叠火柴人
```

**prompt 推导规范（LLM 每 scene 输出 1 个背景 prompt）**：
- 场景主体：用 narration 的关键名词/动作/地点实体化（3-8 个词）
- 风格锁定前缀（全频道固定，保证画风统一，⚖ 待定稿）：
  `flat vector illustration, soft pastel palette, no text, no characters, simple clean composition, ` + 场景主体
- 无文字约束显式写入：`no text, no words, no letters, no signage`
- 火柴人站位预留：`subject placed on the right side, empty space on the left-center`（火柴人默认站左下，主体让位右侧；⚖ 确认左右位）
- 竖屏：`9:16`（minimax 原生 aspect_ratio；imagen 备选映射 9:16）

**一致性策略（minimax 核心收益）**：
- 风格前缀固定 + **每集同一 seed 族**（seed = 集号×100 + scene 序号，⚖）→ 跨 scene 画风连续
- 色板锁定：柔和粉彩（与角色黑线/橙点缀的对比度经测试定）

## 3. 火柴人可读性规则

- 背景复杂度上限：中低信息密度，大面积留白或渐变底，避免高纹理区与角色重叠
- 对比度：背景主色亮度 ≥ 60%（浅色系），保证黑线条清晰；若背景深色场景（夜景），火柴人加白色描边光晕（0.5-1.5px，排版层做）
- 角色站位安全区：画面左 1/3 竖带（或右 1/3，⚖），背景主体禁止侵入该竖带
- 合成时背景可加 3-5% 降饱和/高斯模糊（FFmpeg/HTML filter）进一步分离角色

## 4. 品牌物料（logo/banner/封面）仍走模板

- 三套模板（竖屏背景 A 已废弃为场景生成，保留 B 封面 / C logo）适配 minimax 参数：`aspect_ratio`（B=9:16 或 1:1，C=1:1）、`width/height`、`seed` 固定
- 品牌图内同样无字，logo 文字走排版层叠「柴米」字样

## 5. 验证样本（⚖ 待确认后执行）

取 3 个真实叙事场景生成样图，对比 minimax vs imagen：
1. 超市货架（锚定效应案例）
2. 人体器官示意图（「没用的器官」选题）
3. 深夜卧室（「大脑偷偷做决定」选题）

每张产出 9:16，人工/图像审阅对比：服从度（场景主体正确）、无文字率、火柴人可读性（留白是否够）、跨图风格一致性（seed 效果）。

## 6. 多火柴人处理规则（2026-08-25 拍板）

| 项 | 规则 |
|---|---|
| 前景角色数 | 最多 2 个（柴米 + 1 配角） |
| 配角设定 | 同一 RIG/动捕库，线条改灰色系（#666）或加橙色点缀区分；可命名（如「柴友」） |
| 对话编排 | 柴米说话 + 配角听/回应；动捕 clip 复用（wave/point/sit…），同一 GSAP timeline 并行驱动 2 个 pup |
| 3 人及以上 | 禁止——成本高画面乱；用背景剪影或切镜代替 |
| AI 背景约束 | 不变：背景仍零人物，所有人物由 SVG 前景承担（保角色一致性） |
| 双角色站位 | 柴米左 1/3、配角右 1/3，背景主体让到上方/中央 |

技术实现：`InkPuppet.create()` 多实例（每角色一个 mount g），独立 pose，共享 timeline。

## 7. 场景交互位规则（2026-08-25 用户反馈后新增）

背景不只是「好看的留白画」——火柴人需要**与背景物理互动**（睡在床上、站在货架前、指着器官图）。因此每个场景 prompt 必须声明**交互接触面**：

| 交互类型 | 背景 prompt 要求 |
|---|---|
| 躺/坐/站类 | 明确画出接触面（床面/椅面/地面）且**位于画面下部 1/3**，面朝镜头方向留出角色可躺可坐的空间；主体（床）居中偏下，上部留白 |
| 指/讲解类 | **火柴人站中央偏下偏左（安全位=画面中央区域）**；被指对象（器官图/货架/图表）置于**中上偏右**（画面右上 1/3 区域，非贴边），**尺寸适中（约 1/3 画面高，不巨大）**；主体禁止贴边、禁止沉底小图 |
| 环绕类（多角色） | 接触面 + 两侧留白，背景主体居中偏上 |

**关键修正（相对 v1/v2/v3）**：安全位=画面中央区域（火柴人尽量靠中间偏下偏左）；主体（被指对象）**中上偏右、尺寸适中**（约 1/3 画面高，不巨大、不贴边、不居中、不沉底）。

## 8. 布局分布图（定稿契约，2026-08-25 用户拍板）

**坐标即契约**：AI 背景只负责「画面填满 + 内容偏中上」，**位置全部由排版层按坐标硬叠**（HTML/FFmpeg），不依赖 AI 摆位。布局图：`prototypes/layout-diagram.html`。

1080×1920 画布：

| 区域 | 坐标 | 说明 |
|---|---|---|
| AI 背景 | 铺满全帧 | 只要求画面填满、主体内容偏中上 |
| 讲解对象位 | x600–1000, y180–900 | 中上偏右，高度≥640px（≥1/3 帧） |
| 柴米安全位 | x300–560, y620–1240 | 中左偏中，**身高≈620px（约 1/3 帧）** |
| 字幕安全区 | x90–990, y1560–1750 | 2 行内，避开底部遮挡 |
| AI 标识 | 右上 78×26 | 强制 |
| 集数角标 | 左上 64×26 | 排版层叠 |
| 上下遮挡安全区 | 各 40px | 不得放关键内容 |

执行规则：柴米与对象上下错开（柴米中左、对象右上）、字幕底部独立，互不重叠；背景 prompt 禁止「empty space / plain」类词（实测导致 minimax 生成近白图），改用「画面填满 + 简单背景元素（渐变墙/地面线/角落装饰）」。
