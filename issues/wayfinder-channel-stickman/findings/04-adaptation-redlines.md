# 04 「结构借鉴+改写」红线操作定义（提案 v1，待人审）

> 工单《「结构借鉴+改写」红线操作定义》产出。标 ⚖ 项需用户拍板；其余按默认执行。

## 1. 允许保留（白名单）

- **核心观点/心理学概念本身**：知识点属公共领域，可保留（如「损失厌恶」「峰终定律」）。
- **论证骨架**：钩子→论点→案例→反转→结论的段落顺序与节奏结构。
- **案例主题方向**：可保留「用超市定价讲锚定效应」这类主题级描述。

## 2. 必须改（改写义务，全部满足才算合格）

| 项 | 标准 |
|---|---|
| 全部措辞 | 中文重写，禁止逐句对译腔；口播稿与原转录稿逐句对照不得出现「同序同义句」 |
| 案例本地化 | 原案例（美式超市/职场等）必须替换为中国语境等价物（菜市场/拼多多/职场加班等）；人物名、地名、品牌全换 |
| 文化语境转换 | 玩笑/俚语/宗教政治敏感梗一律弃用或替换为中文互联网通行表达 |
| 数字与引用 | 原片引用的实验/论文保留事实，但表述方式必须重写并注明「有研究显示」级别措辞 |
| 开头钩子 | 必须原创，禁止复刻原片前 15s 的悬念句式 |

## 3. 禁止（红线，触发即打回）

- 原句直译 / 语序微调的同义替换（判定见 §4）；
- 复制原片**专有桥段**：独特的比喻、段子、口头禅、角色设定；
- 复刻原画面构图/分镜（本管线视觉为全新火柴人 + AI 背景，天然隔离，但脚本中的画面指令也不得描述原片镜头）；
- 使用原片出镜者姓名/声音/肖像相关素材；
- 原频道名称、口号、标志性开场白出现在成片中。

## 4. 自查机制（可执行验收）

1. **工具对照**：改写稿 vs 原转录稿做逐句 embedding 相似度（或 n-gram 重合率），阈值 ⚖ 默认：**单句相似度 ≥0.75 判红，整篇 ≥0.45 判黄需人工复核**。
2. **三查抽查**：每集随机抽 5 句人工对照（开头钩子、核心论点句、最长案例句必抽）。
3. **红线清单勾选**：§3 五条逐项勾选，存入 `script_review.md` 与切点表一起人审。
4. **责任链**：LLM 初稿 → 自动相似度扫描 → 人审闸门（脚本闸门同一停机点）→ 通过后解锁 TTS/生图。

## 5. 与其他工单接口

- 本红线在管线中挂载于**脚本闸门**（human_approval_default=true），与《分集切分规则细则》的 split_review 同一人工停机点合并审。
- 升格为「观点级重创作」时另起地图，本文件届时整体作废重写。
