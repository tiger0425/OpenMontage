# 调研与设计结论：小老虎角色圣经原型

工单: 《小老虎角色圣经原型》

## 1. 定案概要

针对 lofi 音乐频道特有的「超长时视觉陪伴、低认知负荷、高情绪治愈」需求，本设计彻底规避了老虎物种易产生的凶猛、肌肉、锐利印象，构建了一套完整的 **Chibi 幼态拟人小老虎角色规范体系**：

1. **角色核心命名**：锁定为 **Tora (小虎)**。简单、国际化、音韵亲切，在欧美和亚洲受众中皆有极高好感度。
2. **三头身圆润解剖学**：圆脑袋、短粗圆爪、粗短圆尾巴。毛色锁定暖琥珀金（`#F5A642`）搭配奶白（`#FFF6E5`）与柔巧克力棕条纹（`#5C3A21`），全面杜绝纯黑尖锐条纹。
3. **伴侣动物生态池**：设计了 5 种迷你伴侣（小雀 Pip、抹茶蛙 Mochi、仓鼠 Kuri、奶猫 Bao、垂耳兔 Sprout），常驻在小老虎头顶、口袋、杯边或书桌旁，带来生动的双角色互动。
4. **五大沉浸式场景**：雨夜阁楼、森林树屋、雨天咖啡馆、暖炉榻榻米、夜行卧铺列车。全部采用 16:9 横屏，遵循黄金分割与景深对比原则。
5. **微动与一致性锁**：制定了呼吸、眨眼、耳尖抖动与杯口热气等微动层级，并沉淀了跨模型（MiniMax Image / Midjourney）的一致性 Prompt 锚点。

完整角色圣经原型已落盘至：[prototypes/character-bible.md](file:///e:/YifuAIForge/OpenMontage/issues/wayfinder-lofi-tiger/prototypes/character-bible.md)。

## 2. 关键决策记录

- **形象决策**：必须维持 2.5 ~ 3 头身的极简大头比例，拒绝 1:1 兽态还原。
- **构图契约**：严格规定横屏 16:9 黄金分割偏侧站位（占横向 1/3~2/5 空间），将视野留给动态雨窗与温馨桌面，为后续视效微动提供充足的物理空间。
- **服饰辨识度**：默认锁定「大号燕麦/鼠尾草绿套头卫衣 + 复古大耳机」，建立标志性的 lofi 符号烙印。
