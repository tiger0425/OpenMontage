# 项目上下文：lofi 小老虎频道（lofi-tiger）

## 领域范围

构建一条面向 YouTube 的英文横屏（16:9）lofi 音乐与氛围长视频自动化管线：输入场景/音乐主题，产出 ① 英文开号与频道资产包（候选频道名、logo/banner 生图 prompt 模板、英文 SEO 描述与长尾标签池）；② 1-3 小时 lofi 放松/学习/睡眠长视频（AI 原创 lofi 音乐无缝循环 + 环境白噪音 + chibi 小老虎伴侣场景微动循环）。

首波范围为试点跑通：先产出 1 条可验收试点成片与成套品牌资产，人审定案后再固化为完整流水线（`bin/lofi_tiger.py`）。

## 核心术语

### lofi 音乐长视频

针对学习、工作、睡眠场景设计的 1-3 小时长时间背景音视频。要求音频平稳舒适、无突兀爆音或刺耳频率；视觉具备陪伴感与安全感，画面不抢注意力，适合作为常驻副屏或背景播放。

### 小老虎角色圣经（Chibi Tiger Character Bible）

原创 chibi 风格小老虎的完整视觉设定与动作规范：头身比、体态、暖色调（橙黄/奶油白/柔和虎纹）、特征服饰（连帽衫/围巾/大头戴式耳机）。包含其专属伴侣池（小鸟、青蛙、仓鼠等）、常驻活动（写字、看书、喝热饮、趴着发呆、听音乐）与场景互动。

### 微动循环（Micro-loop）

10s~30s 视效微动循环单元。角色保持呼吸、轻眨眼、耳朵轻微颤动、偶尔翻书或喝茶等细微动作；背景叠加雨丝、窗上水汽、咖啡热气、灯光粒子等微环境动态；首尾帧无缝闭环，经长时间重复播放不产生视觉跳变或疲劳感。

### 环境白噪音层（Ambience Layer）

与 lofi 音乐轨并行的环境声音轨（雨声、窗外雷声、壁炉噼啪、夏夜虫鸣、咖啡馆低语）。通过分轨混音算法（AudioMixer）动态控制音乐与环境音音量比（如 70% 音乐 + 30% 雨声），营造沉浸式氛围。

### 长时无缝循环渲染（Stream-loop Composition）

针对 1-3 小时长视频的高效合成架构。鉴于逐帧渲染引擎直接渲染数小时视频会导致渲染瓶颈与巨大磁盘开销，本管线采用「解耦渲染」：
1. 视觉层渲染一段高质量 10s~30s 无缝微动母本（MP4）；
2. 音频层渲染 1~3 小时无缝交叉淡化（crossfade）长音轨；
3. FFmpeg 利用 stream loop 将微动母本与长音轨复用合成，分钟级完成长视频交付。

### 品牌资产包（Brand Kit）

开设全新 YouTube lofi 频道所需的成套视觉与文本资产：频道名（10 个多维度候选）、Logo 生图 prompt（1:1 chibi 居中带头饰）、Banner 生图 prompt（16:9 安全区自适应）、SEO Description 及关键词标签集（lofi hip hop, study beats, rain ambience 等）。

### 脚本与场景闸门

生成长视频前，需经人工审批场景构成（角色活动、伴侣、天气/时间）与音乐试听样本，通过后方可进入小时级批量音频/视频合成。
