# ADR-005 营养健康二创采用「题材复刻 + 完全原创」，不沿用搬运流水线

## 决策

营养健康内容二创（小红书+抖音）新起一条**完全原创**的复刻流水线：以 Simran Selects 为蓝本，借鉴其「补剂 vs 天然食物」等已验证模板的选题与结构，但**脚本、画面、配音全部原创**，深度本地化并做合规改写。不下载、不使用源频道画面与文案。

## 背景

用户提出对营养健康 Shorts 频道内容做二创。调研两个候选频道：Simran Selects（92K 粉、单条最高 570 万播放，成功验证）与 Nourishlife with naila（125 粉、未起量）。仓库内已有 MarkHasara（保留原画面 + 中文二创解说 + 数字人）和 Auto-Dub（搬运配音）两条搬运型流水线。

## 权衡

- **为何不用 MarkHasara/Auto-Dub 流水线**：它们以"保留/使用原画面"为核心。本内容定位为原创题材复刻，受众是国内营养科普人群，逐句搬运英文文案既有版权风险，也不符合国内表达习惯与医疗合规要求。
- **为何复刻 Simran 而非 Nourishlife**：二创要复刻"被市场验证过的成功模板"，Simran 的三类选题模板（替代/对比/对决）是 570 万播放的引擎；Nourishlife 未验证，仅作补充题材池。
- **为何深度本地化 + 合规改写**：国内平台对营养健康内容的疗效断言有医疗合规审查，必须避免「治疗/预防」类表述。
- **为何新开垂直账号**：健康饮食是强垂直内容，并入已有搬运号矩阵会稀释权重且定位冲突。

## 结论

- 蓝本：Simran Selects；补充题材池：Nourishlife with naila
- 形态：小红书图文笔记 + 抖音文字卡视频，一源双发
- 账号：新开垂直健康饮食号，目标 25-40 岁关注减脂/养生的女性
- 落地：`docs/nutrition-recreation-channel-analysis.md`（拆解）、`docs/nutrition-recreation-topic-library.md`（选题库）、CONTEXT.md 新增「营养健康题材复刻」上下文
