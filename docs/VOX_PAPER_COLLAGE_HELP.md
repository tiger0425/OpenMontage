# vox-paper-collage 自然语言帮助

## 这条管线做什么

`vox-paper-collage` 用 VOX ANIMATIONS 的老报纸档案拼贴风格制作纪录片视频，包含：

- 选题与事实核查
- Fern 风格连续旁白
- 节拍级分镜设计
- 独立元素生成与分层组装
- HyperFrames HTML/GSAP 动画
- IndexTTS2 配音、背景音乐与纸张特效音
- 横屏或竖屏导出

用户不需要手写 JSON，也不需要自己调用图片、配音或渲染工具。直接用自然语言描述需求即可。

## 最小启动格式

直接发送下面这种话：

```text
用 vox-paper-collage 做一个 1 分钟中文视频。
领域是 money and power，主题是这两天日元汇率拉升。
先核实新闻事实，再按审批流程推进，横屏和竖屏都要。
```

最少需要提供：

| 信息 | 是否必填 | 示例 |
|---|---|---|
| 主题 | 必填 | 日元汇率拉升、某次历史灾难、一个金融丑闻 |
| 时长 | 必填 | 30 秒、1 分钟、2 分钟、3 分钟、5 分钟 |
| 旁白语言 | 必填 | 中文、英文、日文 |
| 领域 | 推荐填写 | money and power、history、crime and documentary |

如果没有指定领域，agent 会先询问；如果没有指定旁白语言，默认英文。

## 推荐启动模板

### 财经新闻

```text
用 vox-paper-collage 做一个 1 分钟中文财经新闻纪录片。
领域是 money and power，主题是日元近期快速升值。
先搜索并核实最近两天的汇率、政策和新闻来源。
提到涨跌时使用真实数据图表，不要画装饰性曲线。
真实新闻照片作为 img2img 参考，生成统一的 VOX 拼贴元素。
横屏和竖屏都生成，不要覆盖以前的版本。
```

### 历史题材

```text
用 vox-paper-collage 做一个 2 分钟中文历史纪录片。
领域是 history，主题是 1985 年广场协议如何影响日元。
使用真实历史照片作为参考，标出日期、人物和关键数字。
先给我 10 个选题，再等我选择。
```

### 犯罪纪录片

```text
用 vox-paper-collage 做一个 30 秒英文 crime and documentary 视频。
主题是一个有明确日期、地点和人物的历史案件。
事实必须可核查，避免血腥画面，使用文件、地图、地点和时间制造张力。
先给我选题和制作方案，不要直接生成资产。
```

### 直接指定选题

```text
用 vox-paper-collage 做一个 1 分钟中文视频。
领域是 technology，直接做“某芯片公司在 2024 年转型的关键一周”。
不需要先给我 10 个选题，但要先核实事实并给出 3 个叙事角度。
```

### 指定画幅

```text
做一个 45 秒中文 vox-paper-collage 竖屏视频，发布到 Shorts。
领域是 money and power，主题是美元兑日元的突然波动。
```

可用画幅词：

- `横屏`：1920×1080，适合 YouTube 长视频
- `竖屏`：1080×1920，适合 Shorts、Reels、TikTok
- `两个版本都要`：分别设计横屏和竖屏构图，不是简单裁剪

## 发送需求后会发生什么

### 第一步：idea

agent 会确认领域、目标观众和主题，并根据需要给出 10 个候选选题或 2-3 个叙事角度。

你可以回复：

```text
1
```

或：

```text
选第一个，采用干预内幕角度。
```

也可以要求修改：

```text
不要讲历史对照，改成市场后果。
```

### 第二步：proposal

agent 会展示：

- 目标时长与旁白字数
- 图像、TTS、音乐和音效工具
- HyperFrames 渲染路径
- 预估成本
- 真实新闻素材与 AI 素材的使用方式
- 横屏/竖屏交付计划

批准方式：

```text
批准方案。
```

如需调整：

```text
预算不变，先只做横屏。
```

### 第三步：script

agent 会生成 Fern 风格连续旁白：

- 冷开场包含日期、地点和具体动作
- 连续叙事，不添加章节标题或镜头指示
- 每个句子表达一个完整想法
- 事实有来源，不确定内容不编造
- 最后以不超过 12 个词的悬念句结束

中文旁白按实际 IndexTTS2 语速规划，通常约 4-5 字/秒，不再把英文 2.5 words per second 直接套到中文。

批准方式：

```text
旁白批准，继续。
```

修改方式：

```text
第 2 段太抽象，增加具体数字，不改变结尾。
```

### 第四步：scene_plan

这是最重要的视觉设计阶段。agent 不只写“放一张图片”，而是为每个分镜建立完整元素契约：

```text
每个分镜：
  背景层
  hero 图片层
  2-3 个相关图片层
  headline / label / stamp / tape / pin / string 等装饰层
  每层的坐标、旋转角度、叠放顺序
  入场动画、微动效、落地音效
```

默认建议：

- 1 分钟成片使用约 6 个视觉分镜，每拍至少 7 秒
- 每拍通常 8-12 个元素
- 元素落位后覆盖约 85% 画面，避免大片空白
- hero 占主要视觉权重，其他元素围绕叙事关系排布
- 元素可以叠压：图章盖在地图上、标签压住照片、胶带跨接两层
- hero 使用整个分镜一次极慢的 push-in 或漂移
- 辅助元素可以使用较轻的 sway、lift、pulse 循环

审批方式：

```text
分镜批准，继续生成素材。
```

修改方式：

```text
第 3 拍不要放硬币和箭头，改成正式的 USD/JPY 走势图。
```

### 第五步：assets

素材策略由内容判断，不是一刀切：

| 内容 | 处理方式 |
|---|---|
| 真实新闻事件 | 找真实新闻图，作为 `img2img` 参考，生成符合 VOX 风格的独立元素 |
| 抽象数据 | 直接生成单一 VOX 元素或用真实数据生成图表 |
| 建筑、地标、物体 | 有真实参考时优先使用参考生成，无参考再直接生成 |
| 胶带、图钉、印章、标签、红绳 | 优先用 CSS/HTML 生成 |

最重要的图片规则：

```text
一张生成图 = 一个独立元素。
```

生成图不应该同时包含地图、照片、标签和印章。多元素构图由 HyperFrames 在 HTML 中完成。

真实新闻图也不是默认原样贴进视频，而是：

```text
真实新闻图 → image_path/img2img 参考 → VOX halftone/剪报风格独立元素 → 抠透明 → GSAP 组装
```

当旁白提到升降时，使用真实数据图表或明确的数据视觉，不画与数据无关的装饰曲线。

### 第六步：compose

HyperFrames 会根据 scene_plan 组装 HTML：

- 背景先出现
- hero 图片层入场并慢速推近
- 相关图片层按叙事顺序分别入场
- 标签、图章、胶带、图钉和红绳按叠压关系落位
- 元素落地时播放低音量纸张特效音
- BGM 低音量铺底并对旁白 ducking
- 旁白使用合并后的单个 WAV，避免分段断音
- 每个分镜从入场到结束持续有运动

技术检查包括：

- `hyperframes lint`
- `hyperframes validate`
- `ffprobe` 分辨率、时长、音频流检查
- 关键帧检查元素是否真的在动
- hero 最终状态是否保持构图稳定

### 第七步：publish

agent 会给出：

- 成片路径
- 横屏/竖屏路径
- 3 张 Thumbnail DNA 缩略图
- 标题、描述和标签
- 实际成本
- 未发布的导出包

发布前仍需你确认：

```text
确认发布。
```

如果只想导出、不上传：

```text
只导出文件，不要发布到平台。
```

## 过程中可以使用的文字指令

### 继续

```text
继续
批准，继续
通过，进入下一阶段
```

### 修改脚本

```text
重写第 2 段，保留事实和悬念结尾。
中文旁白改得更像新闻播报，但不要加章节标题。
```

### 修改分镜

```text
第 3 拍以走势图为 hero，其他元素退到辅助层。
第 1 拍的图章要盖在地图上，不要单独放在角落。
所有分镜减少空白，元素覆盖至少 85%。
```

### 修改动画

```text
hero 图只做整拍一次的慢速推近，不要快速来回缩放。
辅助标签可以轻微循环，但不要让所有元素同时抖动。
把第 4 拍的走势图画线时间延长到整个分镜。
```

### 修改声音

```text
旁白保持自然语速，不要 speed 变速。
把旁白合成一个连续音轨，去掉段落之间的空隙。
音乐降低，旁白必须始终清楚。
```

### 保留旧版本

```text
重新生成，但不要覆盖现有版本，输出到新版本目录。
```

### 暂停或回退

```text
先暂停，不要生成资产。
返回 script 阶段修改旁白。
返回 scene_plan 阶段重新设计元素。
```

## 新闻题材的推荐写法

财经或时事新闻最好把以下内容写进启动文本：

```text
这是近期新闻，请先核实事实。
新闻时间范围是最近两天。
所有数字、日期、人物和政策动作必须保留来源。
涨跌部分使用真实数据走势，不要用抽象装饰曲线替代。
真实新闻图只作为 img2img 参考生成 VOX 风格元素。
```

如果你有指定新闻链接，可以直接附上：

```text
用这个 Reuters 链接作为事实来源：<URL>
```

如果有 PDF、品牌指南或参考素材，可以说明：

```text
我会提供一个 Source Material PDF，请在 idea 阶段吸收它的写作和视觉规则。
```

## 推荐的完整启动示例

```text
用 vox-paper-collage 做一个 1 分钟中文财经新闻纪录片，横屏和竖屏都要。

领域：money and power。
主题：日元最近两天快速升值，可能与美日联合干预有关。
时间范围：最近两天。
事实要求：先搜索 Reuters、官方公告和汇率数据，所有数字和日期保留来源。
视觉要求：
- 真实新闻图作为 img2img 参考，生成 VOX 风格的独立拼贴元素；
- 一张图片只生成一个元素，不要把整张拼贴图一次生成出来；
- 涨跌部分使用真实 USD/JPY 走势图；
- 每个分镜设计 8-12 个元素，hero、相关图片层和 CSS 装饰层分别动画；
- hero 只做整拍一次的极慢推近，辅助元素使用轻微循环；
- 元素落位后覆盖至少 85% 画面，避免静态 PPT 感。

先给我 3 个叙事角度和制作成本，等我批准后再生成资产。
```

## 输出文件位置

默认项目目录：

```text
projects/<项目名>/
├── artifacts/       # brief、proposal、script、scene_plan 等阶段文件
├── assets/          # 新闻图、独立元素、旁白、音乐、SFX
└── renders/         # final.mp4、横屏/竖屏导出
```

版本迭代时使用新目录或明确的版本文件名，不覆盖已确认的成片。

## 高级命令行入口

普通用户不需要执行这些命令。需要手动检查管线状态时可用：

```powershell
python bin/omo.py status --project <项目名> --pipeline vox-paper-collage
python bin/omo.py start-stage --project <项目名> --pipeline vox-paper-collage
```

标准阶段顺序：

```text
idea → proposal → script → scene_plan → assets → edit → compose → publish
```

通过自然语言启动时，agent 会代替你执行这些阶段命令、读取 schema、提交 artifact 和处理 checkpoint。
