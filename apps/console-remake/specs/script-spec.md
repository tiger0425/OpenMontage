# console-remake · 中文脚本与分幕规范（script-spec）

> 适用：撰写 `projects/console-<slug>/artifacts/episode.json`。
> 世界宪法：`design-system.md`（零件/色彩/动效/禁用）；红线：`SKILL.md` 第 4 节。

---

## 1. 文案铁律（去 AI 腔 + 口播）

1. **短句**：以 12~24 字为主；一句一个意思；逗号处能换气。
2. **口语化**：像一线工程师聊天；禁"从本质上讲/值得注意的是/换句话说/众所周知/毋庸置疑"等书面腔。
3. **数字汉字化**：旁白里写"四到十五倍""八千到三万个 token"；画面巨数字用阿拉伯（`15×`）属设计元素。
4. **术语保留**：Harness / Agent / token / context window（上下文窗口）/ Prompt / Claude Code / Codex 保留英文原词；首次出现可在画面给中文注解。
5. **禁用破折号堆叠**：旁白里以"。"为主；视觉文字可用"—"。
6. **钩子开场**：前 3 句内给出"反常识 + 具体物"（例：跑分数字下面那行小字）。
7. **收尾**：回到开场意象（"那行小字"），留一句可被引用的判断。
8. **结构借鉴 + 独立重写**：可沿用参考片的论证骨架（论点顺序/案例类型），**禁止**逐句翻译、禁止复刻其具体措辞。

## 2. 分幕结构（scene / line / chapter）

- **scene**：一个视觉舞台（一组零件 + 一次构图重置），建议 15~30 秒。
- **line**：一句旁白 = 一次口播 = 一次 TTS 段 = 一组零件的入场时机。建议 3~7 秒。
- 每 line 必须有 `elements`（至少 1 个零件）；台词说到什么，零件就出现什么（100% 咬合）。
- **幕间呼吸**：`scene_gap` ≥0.6s；幕尾 `hold_after` ≥0.5s（让画面停一拍再走）。
- **chapter（必配）**：`episode.chapters` 声明 6~10 个章节（`{title, scene}`），
  驱动 HUD 顶栏翻页与进度轨刻痕——观众靠它定位；章名用「序号+主题」句式。
- **空间纪律（HUD 常驻后）**：内容区落在 **y ∈ [96, 940]**（顶部 76px 让给顶栏、底部让给进度轨与字幕条）；
  横向仍守 120px 安全边距（HUD 画框在 16px 处，元素不必避让）。

## 3. 零件选择速查（写分幕时对照）

| 想表达 | 用零件 |
|---|---|
| 两条路 / 前后对比 / 待填 | `frame`（空心描边框，蓝↔红） |
| 预算 / 占用 / 窗口比例 | `grid`（数据格阵 + `divider`） |
| 状态 / 名词 / 对比词组 | `pill`（solid / outline / filled） |
| 分区（替代边框） | `hairline` |
| 关键量级（15×、37¢） | `bignum`（+`count:true` 滚动） |
| 因果 / 流程 / 串联 | `arrow`（`from/to` 引 id） |
| 进度 / 每轮成本 | `slot` |
| 引文 / 官方原文 | `paper`（+`header` 红胶囊 + `highlight`） |
| 事件 / 结论条 | `toast` |
| 仪表底板（衬成本组） | `panel`（`tone:"deep-red"`） |
| 稀疏标题词 | `text`（可 `strike` / `align:center`） |
| 来源行 | `source` |
| 收尾印章 | `seal` |
| 真实人物/产品/项目/界面/地点 | `image`（真实图片 + `provenance` 必填；见 SKILL.md §9） |

**呼应律检查**：本幕主角色的语义色，必须在另一处同色出现（例：红胶囊 ↔ 红格阵）。
**真实素材检查**：本句主体是真实存在的实体吗？是 → 必须用真实素材（image/footage），
不许 CSS 假扮、不许 AI 编造真人；抽象概念/结构/数据才用九零件 CSS。

## 4. 音画咬合写法

- 元素默认在所属 line 起点入场；句内分步用 `enter_offset`：
  - 先框后内容：`frame +0.1` → `内容 +0.6`
  - 先两条路后箭头：`pill A +0.6` → `pill B +1.3` → `arrow +2.1`
  - 收束结论最后：`toast +1.0`
- 箭头必须**晚于**它连接的两个端点入场（箭头时长 0.38s）。
- 巨数字 `count:true` 放在该 line 讲到数字的瞬间（+0.1~0.3）。
