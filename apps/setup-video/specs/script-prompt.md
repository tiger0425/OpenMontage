# setup-video 脚本工单（agent 写 episode.json 的操作规范）

> 输入：`artifacts/ocr.json`（OCR 数值）、`artifacts/transcript.json`（原视频解说转写）、`projects/setup-video-template/TEMPLATE.md` v0.2（模板契约）
> 输出：`artifacts/episode.json`，必须通过 `schemas/artifacts/setup_video_episode.schema.json` 校验
> 放行：`python bin/setup_video.py approve-script <id>`

## 你的任务

为一条调校视频写 6 段中文解说 + 全部模板字段。**车是主角，数值是硬货，口播说人话。**

## 结构（固定 6 幕）

| 幕 | 内容 | 解说目标字数* |
|---|---|---|
| s1 钩子 | 车+赛段钩子（针对该车/该赛段写痛点，不通用套话） | 20–28 字 |
| s2 第一招 | 三招之一：数值 + 人话口诀 | 40–52 字 |
| s3 第二招 | 三招之二 | 32–44 字 |
| s4 第三招 | 三招之三 | 32–44 字 |
| s5 快闪 | 其余照抄（口诀 3 条：随配置图逐条弹出） | 26–36 字 |
| s6 定格 | 收尾 CTA（暂停抄作业/晒圈速） | 20–28 字 |

\* 按中文语速规划。**2026-08-28 首次真机实测校准**：IndexTTS-2.5（my_voice 情绪克隆）短句语速 ≈ **5.0 字/秒**（6 段 179 字 → 34.4s 实长）。因此 60s 目标成片 ≈ 240-260 字解说；40-55s 精简版 ≈ 170-220 字。`approve-script` 预算闸按保守 3.4 字/秒规划（规划值偏长），**最终以渲染后实测时长为准**（QA 闸 40–67s）。

## 三招选择规则（D7）

1. 从 `transcript.json` 找博主**花口播时间最多、语气最强调**的 3 个调校项；
2. 用 `ocr.json` 校验数值真实存在（对不上以 OCR 为准）；
3. 候选打平时按固定优先级：防倾杆 > 差速器 > 轮胎 > 悬挂 > 刹车 > 胎压；
4. 槽位标签带类别英文名（如 `第一招 · 防倾杆 AXLES`）；s5 快闪/s6 白卡照 OCR **全量填 8 行**，不受三招影响。

## 数值口播化（硬规则，wrc LESSONS 沿用）

- 数值读法写中文：`13650` → "一万三千六百五"；`32.0` → "三十二"；`-2.7°` → "负二点七"。
- **裸数字+顿号禁用**（IndexTTS 读法不对）；年份语义要写成"零三年、零四年"这类。
- **外文品牌名一律写中文**：Citroën→雪铁龙、Peugeot→标致、Toyota→丰田、Loeb→勒布……
- 卡片/表格字段（`v1/u1` 等）保留阿拉伯数字+单位（那是给眼睛看的），只有 narration/chips/renhua 做口播化。

## 文案红线

- 过 `banned-words.md` 自检（极限词、诱导、站外导流类词一律不写）。
- 不编造 OCR 里不存在的数值；不确定的留空并在 `notes` 里说明（人核会看）。
- 钩子针对具体车/赛段写（"黑冰打滑"是蒙特卡洛专属语境，换车换赛道必须换钩子）。
- **`video.hook`（s1 金句，v0.3 必填）**：12 字内收益句，句式"<赛段痛点解决> · <收益>"（如"窄弯跟手不推头 · 出弯更稳"/"软基不推头 · 出弯更稳"）。**漏填 = s1 无金句**（生成器按空字符串跳过），批量前逐条核对。`video.promise` 可不填（默认"全参数片尾定格 · 长按保存"）。

## episode.json 字段速查（详见 schema）

```json
{
  "video": { "game": "...", "brand": "skoda", "title": "车名", "track": "赛道", "badge": "X · Y 专用", "team_primary": "#hex 或留空由管线采样" },
  "drive": { "in": 105.2, "out": 110.2, "crop": "810:1440:875:0", "slowmo": 1.5, "fallback_image": "" },
  "points": [ { "label": "...", "k1": "...", "v1": "...", "u1": "...", "k2": "...", "v2": "...", "u2": "...", "renhua": "口诀一句", "evidence_ts": 62.0 } ×3 ],
  "flash": [ { "label": "变速箱 · 1档", "img_ts": 10.0 } ×4 ],
  "chips": ["口诀1", "口诀2", "口诀3"],
  "narration": { "s1": "...", "s2": "...", "s3": "...", "s4": "...", "s5": "...", "s6": "..." },
  "table": [ { "name": "变速箱 GEARBOX", "value": "1 档" } ×8 ],
  "package": { "title": "...", "desc": "..." },
  "notes": "给管线/人核的备注"
}
```

- `evidence_ts` / `img_ts` = 该配置界面在**源视频**里的时间点（秒），extract 的采样帧里能对上的那个；assets 阶段按它截配置图。
- 截图一致性硬规则：`img_ts` 必须指向**游戏内配置界面**（tab 栏+车视角+数值），标题卡/零件示意图一律不要（管线会截出来，人核/抽检会打回）。
