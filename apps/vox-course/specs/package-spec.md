# VOX 课程成品包规范 (package-spec.md)

本规范定义了课程视频完成渲染后，交付给用户的最终发布资产包（`package/`）目录结构与元数据要求。

---

## 1. 交付物目录结构

每个课程项目在完成 `package` 步骤后，将在 `projects/<course-id>/package/` 产出如下完整交付包：

```
projects/<course-id>/package/
├── video_1080p.mp4      # 1080P FHD 主成片 (30fps, H.264, 约 50~80MB)
├── video_4k.mp4         # 4K UHD HEVC 超清压制成片 (3840x2160, Main 10, Lanczos)
├── bilibili.txt         # 【核心】B 站一键复制单文档（含 4 款标题、标签行、精准时间轴简介与下集预告）
└── covers/              # 【全平台多比例封面矩阵】
    ├── cover_16x9.png   # 16:9 标准横屏视频封面 (1920×1080)
    ├── cover_4x3.png    # 4:3 动态/推荐流卡片封面 (1440×1080)
    ├── cover_1x1.png    # 1:1 合集大图/正方形卡片 (1080×1080)
    ├── cover_3x4.png    # 3:4 移动端竖版卡片推荐流 (1080×1440)
    └── cover_9x16.png   # 9:16 手机全屏动态/竖屏小视频 (1080×1920)
```

---

## 2. 封面图多比例生成标准 (Multi-Ratio Cover Specs)

- **核心构图原则**：
  1. 采用深灰工业背景 + 撕纸核心卡片；
  2. 核心大字大白话痛点（如：“95% 大模型项目回报率为零？”）与官方印章居中保持在 1080×1080 安全区域；
  3. 带有右上角 **“第 1 集”** 或 **“EP.01”** 的红底高亮标签；
  4. 自动裁切生成 16:9、4:3、1:1、3:4、9:16 共 5 种标准尺寸，无黑边变形，自适应全平台。

## 3. 双标题与文案撰写标准

### 3.1 标题推荐策略
- **主标题（专业度/搜索权重优先）**：
  `绝大多数大模型项目回报率为零？深挖真实 AI 工程的真正底盘 Harness`
- **备用标题（信息流点击率/算法爆发优先）**：
  `砸了300亿美金回报率居然是零？大模型落地翻车的真相，全被这块底盘遮住了！`
