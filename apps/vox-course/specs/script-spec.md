# VOX 课程脚本编写与去AI化规范 (script-spec.md)

本规范规定了如何将原始课程主题、技术文档、论文或大纲转化为标准的 VOX 科技纪录片剧本（`course_episode.json`）。

---

## 1. 经典七幕叙事弧线 (The 7-Beat Arc)

VOX 风格技术/商业课程采用标准的 7 幕递进叙事模式，单集时长通常在 3~5 分钟：

| 幕号 | 章节代号 | 核心目标 | 视觉核心 | 情绪调性 |
|---|---|---|---|---|
| **Scene 1** | REALITY CHECK / 痛点破局 | 撕下遮羞布，爆出反常识数据/反差 | 红色调查档案卡、大头针、反常识数据大字报 | 警醒、冲击 |
| **Scene 2** | THE HARNESS / 认知颠覆 | 指出大众盲区，给出核心概念定义 | 纸张与线缆连线、官方印章、穿梭巨型字体 | 笃定、豁然开朗 |
| **Scene 3** | CATASTROPHE / 传统翻车 | 剖析传统方案为何死循环/腐烂 | 撕纸档案、红色警戒印章、CRT Glitch 频闪 | 压抑、严峻 |
| **Scene 4** | RECONSTRUCTION / 底层重构 | 揭秘真正生产级底层解法 | 终端逐行打印、内存变量高亮、缓存命中日志 | 极客、精细 |
| **Scene 5** | BENCHMARK / 数据说话 | 同权重硬碰硬对比，展示压倒性差距 | 动态折线飙升、差值虚线连接、绿色胜出印章 | 震撼、无可辩驳 |
| **Scene 6** | ECONOMICS / 硬件经济学 | 帮观众算经济账，破除硬件迷信 | 吞吐量对比进度条、高级复印机比喻卡片 | 理性、说服力强 |
| **Scene 7** | MANIFESTO & HOOK / 工业宣言与下集钩子 | 亮出核心结论，无缝抛出下集实战悬念 | 终极核准印章、下集专属预告展板、4秒淡出 | 昂扬、期待拉满 |

## 2. 文案去AI化转换规则 (口播 38+3 条落地指南)

在编写 `narration` 字段时，必须严格执行以下规则：

### 2.1 词汇黑名单与白名单替换
- ❌ 禁：“从本质上讲”、“决定到底”、“无可争议” → ✅ 换：“说白了”、“关键就在于”、“事实摆在眼前”
- ❌ 禁：“正如我们所见”、“众所周知” → ✅ 换：“你瞧这个界面”、“大家平时都以为”
- ❌ 禁：“在这个充满挑战的领域中” → ✅ 换：“扔进真实业务环境里”
- ❌ 禁：“造成了严重的后果” → ✅ 换：“直接原地转圈脑死亡”、“修一个 bug 引出五个新 bug”

### 2.2 彻底粉碎长句
- 任何句子超过 25 个汉字，必须用逗号或句号切断。
- 保证每个逗号代表一个呼吸气口（约 300~400ms）。
- 示例：
  - ❌ “麻省理工二零二五年发布的报告指出全球企业投入了三百亿美金在大模型应用上但其中百分之九十五的项目都没有产生实际的回报率。”（59字无标点，听感窒息）
  - ✅ “但二零二五年，麻省理工的一份重磅报告，直接把遮羞布给扯了。全球企业砸了三百亿美金，结果百分之九十五的项目，回报率干脆是零！”（切成两句，每句带标点气口）

### 2.3 数字汉字化铁律
- 年份：`2025` → `二零二五年`，`2026` → `二零二六年`
- 金额：`$30B` → `三百亿美金`
- Token数：`18432 tokens` → `一万八千多个 Token`
- 百分比：`95%` → `百分之九十五`，`12%` → `百分之十二`
- 数量倍率：`4x` → `四倍`，`16 points` → `整整十六分`

## 3. 音画咬合映射规范 (Audio-Visual 100% Binding)

每一个在 `narration` 中出现的重点词汇，必须在 `display` 中有明确的呈现载体：

```json
{
  "narration": "真正干脏活累活的，是套在模型外面的装具，也就是 Harness！",
  "display": {
    "cards": [
      {
        "title": "THE HARNESS 装具底盘",
        "badge": "PRODUCTION RUNTIME",
        "list_items": [
          "沙箱隔离 (Sandbox)",
          "工具调度 (Tool Broker)",
          "前缀缓存 (Prefix Cache)"
        ]
      }
    ],
    "stamps": [
      { "text": "HARDWARE READY", "color": "orange", "rotate": -6 }
    ]
  }
}
```

严禁台词在讲“IPython 内存池”，画面卡片写的却是“模块通信协议”。

## 4. 下集预告钩子规范 (Next Episode Hook)

第 7 幕末尾必须包含明确的行动号召与下集剧透：
1. **提出核心冲突**：“那么，一套生产级的 Harness 到底该怎么写？”
2. **给出解决方案与预告**：“下一集，咱们直接撕开 OpenHands 的底层沙箱，带你从零手搓一套工业级 Agent 执行底盘！”
3. **收尾关注号召**：“赶紧关注我，带你深挖真实的 AI 工程硬核前线，咱们下期见！”
4. **展板同步亮出**：画面滑出 `#s7-card-next`，印章盖下 `NEXT EPISODE`。
