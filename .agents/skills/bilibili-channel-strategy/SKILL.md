# Bilibili 频道运营策略

## 1. 使用方式

本文件是给 agent 读的运营规则书，不碰 auto-dub 代码。用户喊 §6 触发词表中的
任意一句时，读取本文件并套用对应章节产出结果。三号矩阵已固化在 §3 号档案，
通用规则在 §2。

---

## 2. 通用规则（改一次，三号全员生效）

### 2.1 标题公式

```
【分区】好奇钩子 + 具体细节 + 情感锚
```

- 例子：`【硬核科普】为什么中国高铁能跑350km/h？答案让我震惊`
- 规则：不得虚构原视频内容（翻译号保真）；不用全角空格；字数不硬限但
  保证移动端一屏可读完。

### 2.2 简介模板

```
首行钩子（复述标题的情绪点，不重复标题本身）
- 要点1（视频最有价值的信息）
- 要点2
- 要点3
关注我，<号档案 follow_hook>。
<3-5 个相关标签>
```

### 2.3 封面验收 Checklist

对 auto-dub 产出的封面逐项打勾，任一不通过则重做或重新生图：

- [ ] 大字标题 ≤ 8 个中文字
- [ ] 高对比（缩略图尺寸仍可读）
- [ ] 人脸/表情或原片关键视觉
- [ ] 通过滚动测试：混在 20 张图里能被一眼认出
- [ ] 颜色匹配该号 `cover_style`

### 2.4 发布时间

- 19:30 定时发布，20:00 进推荐，匹配弹幕峰值。
- 周末晚间 20:30 后是集中观看窗口。
- 初值为第三方经验数据，以用户实测为准（见 §5 观测）。

### 2.5 护持期 SOP（发布后 30 分钟）

发布后立即执行，全部在 30 分钟内：

1. 回复前 20 条评论（含全部被删除前的有效评论）。
2. 置顶一条引导（三连/收藏/关注，按号档案 follow_hook）。
3. 动态同步一条发布预告。

**相对指标，不追绝对值**：目标是"零互动残留"（每条评论都被接住），
不是 50 赞 20 评——小号达不到也不该为此焦虑。

### 2.6 弹幕种子（可选）

发布后 1 小时内投放 10-15 条种子弹幕，按时间点触发设计：

| 时间点 | 内容 | 预期回应 |
|--------|------|---------|
| 0:03 | 复述开场钩子 | 观众接话 |
| 中段关键点 | 事实性吐槽/补充 | 讨论 |
| 结尾 | "下次一定" 或系列编号接力 | 老粉应援 |

## 3. 号档案

### 3.1 C 号（现主号，active）

- **定位**：国外 AI 大V 视频中文翻译（开发/应用/行业动态）
- **受众**：泛知识人群
- **差异**：资讯型（大V 观点/演示/访谈翻译），非自制教程
- **选题池**：大V 视频列表链接（找到即投递）
- **节奏**：日更
- **封面风格**：大V 资讯风（原片截图 + 人脸 + 大字 ≤8 字）
- **系列规则**：`AI大V翻译 #N`
- **关注钩子**：每周更新，翻译圈内大V 最新干货
- **关注自动回复**：欢迎关注～这里每天更新一期国外 AI 大V 视频的中文翻译（AI 开发/应用/行业动态），帮你用最短时间跟上圈内最新趋势。觉得有用的话，点赞投币收藏三连是我更新的最大动力，也欢迎在评论区点菜想看的频道/话题，我会优先安排！（新粉可以看看我的合集，往期都在里面）

### 3.2 A 号（新建，active）

- **定位**：免费 AI + AI 搞钱（省钱小白 → 赚钱人群）
- **受众**：想省钱/想靠 AI 副业赚钱的人群
- **差异**：省钱+赚钱双主线
- **选题池**：频道 + 关键词搜索（config 的"免费AI"池即此号）
- **节奏**：周 3-4 更
- **封面风格**：省钱红字风（"免费！""省$20"式大字）
- **系列规则**：`免费AI实战 #N`
- **关注钩子**：每周三更新一期免费AI实战
- **关注自动回复**：欢迎关注～这里每周更新免费 AI 工具和 AI 搞钱实战，帮你不用花一分钱用上顶级 AI。每期都会讲"具体怎么操作、能省/赚多少"，收藏方便回看。评论区说说你现在卡在哪，我挑高赞的下期做！

### 3.3 B 号（新建，active）

- **定位**：开发者省钱实操 + 开源项目盘点
- **受众**：进阶开发者
- **差异**：实操型（教程/项目），区别于 C 号资讯型
- **选题池**：GitHub 热榜
- **节奏**：周 1-2 更
- **封面风格**：硬核深色风（代码/终端截图）
- **系列规则**：`开源黑科技 #N`
- **关注钩子**：每周盘点能省钱的开发者工具与开源项目
- **关注自动回复**：欢迎关注～这里每周盘点能帮开发者省钱、省时间的开源项目和工具，每期都有真实仓库和数据。看到感兴趣的仓库，可以直接在评论区贴链接，我会评测安排！合集里已按工具类型整理好往期。

### 3.4 新增号模板（复制即用）

```yaml
- 定位：<一句话，唯一>
- 受众：<谁在看>
- 差异：<凭什么区别于现有号>
- 选题池：<内容来源>
- 节奏：<daily / weekly3-4 / weekly1-2>
- 封面风格：<颜色/元素，不得与现有号混用>
- 系列规则：<前缀编号>
- 关注钩子：<固定更新承诺>
- 关注自动回复：<欢迎语 + 更新承诺 + 三连引导 + 互动入口（点菜/留言），百字内>
```

## 4. 分支流程

### 4.1 选片

1. 确认目标号（默认 C 号，用户可指定）。
2. 读该号 `选题池`，从候选池筛出符合定位的视频。
3. 对超出定位的内容打标并归到对应号（选题漂移即打回）。

**完成标准**：给出 2-3 条推荐 + 每条一句话理由（为何符合定位），
并标注每条的归属号。

### 4.2 定标题

1. 读目标号 `系列规则` 确认当前编号。
2. 基于直译标题，按 §2.1 公式改写为中文 B站 腔。
3. 核对不虚构原视频内容。

**完成标准**：输出 1 个主标题 + 1 个备选，均套用公式且含系列编号。

### 4.3 写简介

按 §2.2 模板生成，钩子 + 3-5 要点 + 关注钩子 + 标签。

**完成标准**：模板各部分齐全，关注钩子与目标号档案一致。

### 4.4 验收封面

1. 按 §2.3 Checklist 逐项检查 auto-dub 产出封面。
2. 不通过 → 判断是重做（模板路径）还是重新生图（image_selector 路径）。

**完成标准**：Checklist 全部打勾，或已发起重做并说明失败项。

### 4.5 发布

1. 提示发布时间：目标号 `publish_time`（默认 19:30 定时）。
2. 发布后触发 §2.5 护持期 SOP。
3. 提醒弹幕种子投放（§2.6）。

**完成标准**：发布时间与护持期清单已交付用户，无遗漏项。

### 4.6 复盘

1. 读 §5 观测表数据。
2. 按号判断：
   - **C 号**：关注增量是否逐条上升（趋势，非阈值）；选题是否漂移。
   - **A/B 号**：前 10 条是否出现进入二线推荐池迹象（约 1 万播放）。
3. 给出结论：继续 / 换选题 / 降频 / 加投。

**完成标准**：对每个号给出明确判断，且说明依据的数据点。

### 4.7 新增号 / 调整

1. 复制 §3.4 模板填写新档案。
2. 通用规则自动适用，不改 §2。
3. 新增方向同理：仅在该号档案 `选题池`/`定位` 追加。

**完成标准**：新档案字段齐全，且 §2 通用规则零改动。

## 5. 数据观测表

每条视频记一行（存 `projects/bilibili-ops/observation.csv` 或用户自建表）：

```csv
date,channel,video_title,views,likes,coins,favorites,followers_delta,completion_note,source_pool
2026-08-09,C,AI大V翻译 #21,580,23,5,41,+12,中段流失,大V列表
```

复盘规则：
- 收藏 >> 关注是当前核心问题，重点盯 `followers_delta` 趋势。
- 发布时段是初值，数据积累后按用户实测调整（更新 §2.4）。

## 7. 更新协议

- 用户说"更新 skill"时，按其指出的号档案或通用规则做单点修改。
- 每两周围绕 §5 观测表数据复审一次号档案，必要时调整定位/节奏。
