# 文案规范 — 钩子 / 揭晓 / 副注 / 过渡 / 信息卡 / CTA + 抖音标题 & 简介

四段式短视频的文案设计，目标是 **留人 + 引发互动 + 导向关注**，并让每条内容"有叙事、有信息增量"。
所有文案服务于同一条核心主线：**让观众从"看高能画面"升级为"懂背后原理"**，让每一帧都有信息支撑，而非单纯视觉刺激。

---

## 1. 钩子（Hook，0–4s）

- 一句话悬念 + 倒计时 3·2·1，制造"等一等"的期待。
- 要点：短、口语化、指向视频高光、不给答案。
- **悬念递进（可选增强）**：若源视频前 2-3s 是静态/空画面，可以让字幕从"来的是什么?"递进为"它能突破地心引力?"，逐步升级悬念强度。注意：**这只改"字的悬念"**；若要真配"特写/引擎音效"级别悬念，已超出 overlay 能力，需走生成管线。

**通用范本：**
- kicker：`竞猜时间` / `猜猜看` / `倒数三秒` / `3 秒后 · 猛兽登场`
- 主句：`来的是什么？` / `下一秒你绝对想不到` / `能认出来吗？`
- 副句：`🎯它会飞` / `不——它会开` / `答案在高光那刻` / `它能突破地心引力？`

## 2. 揭晓（Reveal）

- 高光瞬间直接打出**答案主体**（车型/物品/人物/结论名），用冲击英文/大字号。
- kicker：`答案是——` / `来了` / `看清没？`
- **性能副注（推荐增强）**：在揭晓词下方加一行 `reveal-note`，把高光时刻绑定"懂原理"，
  例如 `腾空的秘密：轻量化车身 + 涡轮爆发`。让观众从"看腾空"升级为"懂为什么能腾空"。
  ⚠️ 只写**依赛季核实的动力机制**：混动约 2022–2024；2025 起纯内燃。本参考片官方确认为 2026 赛季 → **无混动**，勿写"混动爆发"。

## 2b. 副注层（Annotation，信息增量）

半透明的一行小字，在某个高光动作/赛段瞬间短暂弹出（3–5s 后淡出），不遮主体：
- 赛道：`WRC 芬兰站 · 经典飞跳 ｜ 落差 3 米`
- 动作：`重刹降挡 + 锁定差速器 · 零失误漂移过弯`
- 环境：`维修区快速换胎 · 仅 2.3 秒`
> 一句话一个信息点，别贪多；3–5 秒后自动 fade，别挡住核心画面。

## 2c. 过渡（Transition，揭晓→信息卡）

一段 1.5–2s 的桥接句，让"展示奇观"平滑过渡到"揭秘原理"：
- `腾空的秘密，藏在这台车里`
- `这么猛，凭什么？往下看`
- `答案的细节，全在这份档案里`

## 3. 信息卡（Info Card）

- 标题用中性词：`赛车档案` / `车辆档案` / `产品档案` / `主角档案`。
- 3–8 行关键数据，标签色 + 值色区分，可读优先。
- **数字动效（推荐增强）**：马力/动力等数值用 `<span id="hp-count">0</span>` + GSAP 0→N 递增，把抽象参数做成 0 飙到 N 的冲击动效（N 用**按官方赛季核实的值**）。⚠️ 本片官方确认 2026 → 纯内燃约 380 匹（去混动），勿按旧混动填 500；标"待官方规格确认"。

## 4. 结尾 CTA（放上半屏 + 呼应开头 + 埋伏笔）

```
你猜对了吗？
这台能飞的 <GR Yaris>
下次看它的过弯神技 !
```
- **呼应开头**：第 1 行回扣开头的竞猜设定（`你猜对了吗？`），让单条叙事有始有终。
- **埋伏笔（推荐）**：第 3 行预告"下一集看什么"（`下次看它的过弯神技 !`），强化系列感、引导关注。
- "请关注 XX"的 XX 用**强调色**（赛车＝WRC 红），或改为伏笔句 + 文字"关注"。
- 别在 CTA 里堆信息，聚焦引导关注/求互动/埋伏笔。

## 抖音标题（供用户选用）

### 悬念竞猜向
- 短：`你猜，来的是什么？🕵️` / `倒数 3 秒，敢猜吗？`
- 长：`你猜来的是啥？3·2·1 答案揭晓，看它怎么飞的！🚗💨`

### 视觉震撼向
- 短：`它真的会飞！😱` / `腾空瞬间帅到没朋友 🔥`
- 长：`一台会飞的赛车，腾空那一刻我看了十遍！🏎️`

### 引导关注向
- 短：`后期更精彩，关我别走丢 🔔` / `关注 <频道>，天天看猛车`
- 长：`这场面后期更精彩！关注 <频道>，锁定每期猛车现场 🔔`
