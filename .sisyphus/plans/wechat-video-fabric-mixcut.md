# 微信视频号「面料研究所」搬运策划 —— 多源混剪 + 中文配音

> 计划状态：草案（待用户确认后进入执行）
> 关联系统：`bin/auto_dub.py`（单源整片搬运）、`clip-factory`（单源切多片）
> 核心结论：多源混剪可实现「AI 全自动生产 + 人工抽检」，但现有流水线缺少「多源选段拼接」编排器，需新增。

## 摘要

把 YouTube 面料/服装知识视频以**多源混剪 + 全新中文解说 + 竖屏 + 花字字幕**的形式搬运到微信视频号。
目标账号定位为「懂面料的服装行业内部人」，主打「看懂一件衣服从纱线到成衣」系列。
因视频号原创审核严格，所有内容一律走 **L2 混剪重构**，不做单源整片直搬。

## 背景

- 用户已有 Auto-Dub 系统（YouTube 下载 → Whisper 转录 → LLM 翻译 → IndexTTS2 中文配音 → FFmpeg 压制 → B 站发布）。
- 目标平台改为微信视频号，平台差异：竖屏优先、封面 1:1、标题 ≤30 字、完播率权重高、原创审核更严。
- 已完成面料/服装频道初步调研（Science Channel、Zoe Hong、Textile Vlog、做衣服找胖哥、梅森设计等），并确认首批素材源。

## 目标

1. 建立微信视频号面料知识账号的完整内容生产体系。
2. 打通「多源素材 → 全新中文解说 → AI 配音 → 竖屏混剪成片」流水线。
3. 通过 L2 混剪重构规避视频号搬运审核风险。

## 范围

**包含**：
- 多源混剪流水线设计（新增编排器）
- 视频号适配（竖屏重排、1:1 封面、标题/简介模板）
- 合规策略与发布运营节奏

**不包含**：
- 视频号发布 API 对接（平台无开放上传接口，现阶段手动经视频号助手发布）
- 大规模多频道授权洽谈

## 技术决策

### 流水线（新增，核心交付物）

```
① 选片下载（yt-dlp）→ ② 转录+时间轴（Whisper）
→ ③ 解说脚本（LLM 重写，不复述原文）
→ ④ 选段：LLM 按脚本语义从各源字幕匹配片段（含时间戳）
→ ⑤ scene_detect 校准边界 + frame_sampler 抽帧人工复核
→ ⑥ IndexTTS2 配音 → ⑦ FFmpeg 拼接+竖屏重排+字幕花字+片头尾
→ ⑧ 1:1 封面 → ⑨ review/ 人工审核 → ⑩ 发布视频号
```

- **复用**：`bin/auto_dub.py` 的转录/配音/压制/封面模块
- **新增**：选段编排器（脚本句 → 多源片段时间戳 → 拼接清单），输出 `montage_plan.json` 供审核
- **红线**：所有生产操作走 `bin/omo.py` / `bin/auto_dub.py` 入口，禁止 ad-hoc 脚本

### 多源混剪 AI 自动化程度

| 环节 | 自动化 | 依据 |
|---|---|---|
| 多源下载 | ✅ 全自动 | yt-dlp（video-download） |
| 转录+时间戳 | ✅ 全自动 | Whisper（auto-dub 已用） |
| 按新脚本选片段 | ✅ 全自动 | LLM 读字幕时间轴 + `scene_detect` 校准 |
| 画面-解说匹配 | ⚠️ 半自动 | `frame_sampler` 抽帧复核 |
| 裁剪拼接 | ✅ 全自动 | FFmpeg |
| 中文配音 | ✅ 全自动 | IndexTTS2 本地 GPU |
| 竖屏/字幕/封面 | ✅ 全自动 | FFmpeg + 现有封面模板 |
| 片段边界/版权/成片抽检 | ❌ 人工 | 平台审核 + 版权红线 |

## 合规策略（视频号核心红线）

- 全程 **L2 混剪**：单一来源占比 ≤60%，多源拼接 + 全新中文解说 + 统一角标水印
- 简介固定标注「素材来源 + 编译」，保留出处
- 优先用 How It's Made 官方频道；Zoe Hong 只取概念观点、不整段搬运
- 成品进 `review/` 人工审核后再发布；发布前自查：单源占比、品牌 logo 长镜头、解说与画面错位

## 运营节奏

- **冷启动**：2 周日更 1 条（先做 5 条打样），主攻完播率 >45%
- **稳定期**：周更 3-4 条 + 系列化（《一件衣服的诞生》）
- **钩子**：文末引导关注公众号领「面料术语表」；直播答疑
- **发布时间**：晚 7-10 点；复盘完播率/转发率

## 执行阶段

| 阶段 | 内容 | 产出 | 闸门 |
|---|---|---|---|
| **P0** 决策 | 定账号名、首批 5 个选题 | 选题清单 | 用户确认 |
| **P1** 建流水线 | 新增多源混剪编排器 + 视频号适配（竖屏/1:1 封面） | `montage_plan` schema + 工具 | 代码评审 |
| **P2** 素材库 | 下载首批 5-10 条 Science/Zoe 视频，转录建索引 | 素材索引 | — |
| **P3** 打样 | 跑通 1 条样片（羊绒选题） | `review/` 样片 | 用户审片 |
| **P4** 量产+发布 | 批量生产 5 条 → 视频号发布 → 48h 数据复盘 | 成品+复盘报告 | 数据门 |

## 风险与约束

- **版权**：无授权搬运有被投诉/限流风险，依赖 L2 重构缓解；How It's Made 等大厂内容商业化需进一步评估
- **平台**：视频号无开放上传 API，发布环节需手动
- **技术**：多源混剪编排器为新增开发，需评审验证
- **数据**：账号冷启动数据存在不确定性，需按复盘迭代选题

## 成功标准

1. 多源混剪流水线跑通并产出 ≥1 条可发布样片
2. 样片通过人工审核与视频号原创合规自查
3. 冷启动期 5 条成品全部产出，完播率 ≥45%
