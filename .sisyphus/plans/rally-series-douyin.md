# 拉力赛游戏进化史 · 抖音系列企划

## 摘要

基于已下载的《拉力赛游戏进化史》参考视频（`temp_rally_video.mp4`，19 分钟，1988–2022，约 80+ 款游戏实机 montage），拆解为 22 期抖音竖屏短视频系列。每期采用统一的「钩子 → 5 秒片头 → 正片剪辑 → CTA」模板，游戏画面取材自原片对应时间段，配中文口播（本地 GPU TTS）。先制作 EP.01（1988 Lombard RAC Rally）样片验证模板，确认后批量复制到其余期。

## 背景

### 源头素材

- **参考视频**：`E:\YifuAIForge\OpenMontage\temp_rally_video.mp4`（720p，时长 1137.354s，1280x720）
- **内容**：1988–2022 拉力赛游戏按年份升序 montage，每款 5–15 秒实机画面，约 80+ 款游戏，无旁白、保留游戏原声 + 领航员 pace notes 语音
- **已完成的素材**：
  - 场景检测帧：`temp_rally_video_frames\`（69 帧）
  - 完整转录：`temp_rally_video_transcript.json`（165 段，Whisper base，含全部游戏名/年份及对应时间段）
  - 四时代幕划分：1988–1993 街机/16-bit → 1994–2000 3D 萌芽 → 2001–2009 3D 成熟 → 2010–2022 高清写实

### 赛道调研

- "游戏进化史"为已被验证的内容赛道：Game Evolution（如《Tekken Game Evolution 1994-2024》26:41，30.5 万播放）、Video Games Evolution 频道（约 30 万订阅、8179 万总播放）
- 竞品多为横屏中长视频；**竖屏 + 每期单游戏深挖 + 中文口播**为差异化切入口，且抖音对 1 分钟以内的竖屏短内容分发友好

### 关键约束

- 当前模型不支持图像输入，画面细节以转录 + 场景帧时间戳为准
- 原片为单一画面源，需在竖屏 9:16 画幅下复用（背景模糊 + 画面居中裁剪），并叠加口播与字幕
- TTS 走 `tts_selector` → 本地 `voxcpm_tts`（VoxCPM2，中文引擎，GPU 已确认可用：RTX 3090 24GB，torch 2.10 cuda 可用）

## 目标

1. **可复制模板**：定义统一的单集结构（钩子 → 5 秒片头 → 正片剪辑 → CTA），22 期套用
2. **系列化**：严格按年份升序，让观众"追更进化史"主线，形成系列心智
3. **低成本批量**：原片剪辑 + 本地 TTS，零第三方 API 成本（除图片/字幕装饰可选）
4. **差异化**：竖屏、单游戏深挖、中文口播，区别于横屏横评竞品
5. **验证优先**：先做 EP.01 样片，确认风格后再批量，避免 22 期方向性返工

## 范围

### 包含

| 组件 | 说明 |

### 不包含

- 不重新下载各游戏独立实机素材（版权 + 成本考虑，复用原片内已有画面）
- 首版不做 AI 生成画面（历史实机画面无法还原，失真风险高）
- 不做横屏版本（抖音竖屏优先）
- 不接入第三方 TTS API（本地 VoxCPM2 满足中文口播需求，零成本）
- 暂不做 B 站/YouTube 横版适配

## 技术决策

| # | 决策项 | 结论 | 理由 |
|---|---|---|---|
| 1 | 单集结构 | **钩子(0–3s) → 5 秒统一片头 → 正片剪辑 → CTA** | 抖音前 3 秒流失率高，钩子最前置；片头统一系列心智 |
| 2 | 5 秒片头 | **统一系列片头**：系列 LOGO/标题 + 年份大字，每期只换 EP 编号与年份 | 强化"拉力赛游戏进化史"系列认知 |
| 3 | 分集粒度 | **里程碑单集 + 年代合辑混合**（22 期） | 全 80+ 集太长；单游戏深挖讲故事的留单集，冷门同代合并 |
| 4 | 排序 | **严格年份升序** | 追更逻辑 + 进化史主线 |
| 5 | 画面来源 | **原片按时间段裁剪复用** | 版权安全（自购/自有素材）、零成本、真实历史实机画面 |
| 6 | 竖版处理 | 16:9 居中裁剪 + 上下模糊背景填充，保持主体完整 | 抖音 9:16 标准画幅 |
| 7 | TTS | **`tts_selector` → `voxcpm_tts`**（VoxCPM2，中文） | 本地 GPU 零成本；固定 seed/锚点保证跨期音色一致 |
| 8 | 口播 | 中文，1 分钟约 260–320 字 | 目标平台为抖音（中文用户） |
| 9 | 字幕 | 口播逐句烧录字幕（可选，样片阶段决定） | 抖音静音观看比例高，字幕提升完播率 |
| 10 | 工具 | ffmpeg（裁剪/合成/字幕）+ 临时 python 脚本调 `tts_selector` | 已验证可用；遵循 AGENTS.md 用 selector 而非直连 provider |

### 单集结构细化（约 60 秒）

```
0–3s    钩子：震撼/反差开场（如"1988 年的赛车游戏长什么样？"）
3–8s    5 秒统一片头：系列标题 + 年份大字 + EP 编号
8–55s   正片：原片该游戏片段 + 中文口播 + 字幕
55–60s  CTA：关注/下期年份预告
```

### EP.01 样片制作步骤

1. 用 ffmpeg 从原片裁剪 0:00–0:10 Lombard RAC Rally 片段
2. 将片段转为 9:16 竖版（居中裁剪 + 上下模糊背景）
3. 通过 `tts_selector` 生成 EP.01 口播 WAV（VoxCPM2，固定 seed）
4. 用 ffprobe 检测口播时长，微调剪辑节奏对齐
5. 拼接：钩子(0–3s) → 片头(3–8s) → 正片 → CTA
6. 叠加口播字幕（如需）
7. 输出 `final.mp4`，ffprobe 校验，交用户审阅

## 风险与约束

| 风险 | 级别 | 缓解措施 |
|---|---|---|
| **单一片源复用 22 期导致画面单调** | 中 | 竖版裁剪 + 节奏错位 + 口播内容差异化；年代合辑集天然多游戏切换 |
| **TTS 音色不理想** | 中 | VoxCPM2 支持 voice_description 描述 + 固定 seed 锚点；必要时调 cfg/步数 |
| **口播 1 分钟稿难配 60s 节奏** | 中 | 先合成口播测时长，再按音频实际长度调整剪辑（以音频为基准） |
| **原片段时长不足（部分游戏仅 3–5s）** | 中 | 正片可循环/慢放/叠加速剪；里程碑单集选片段充足的游戏 |
| **Whisper 误听导致游戏名/年份错误** | 中 | 口播稿撰写时交叉核对 MobyGames/Wikipedia |
| **抖音版权判定（游戏实机画面）** | 低 | 原片画面为各游戏片段 montage，属评论/展示范畴；抖音以内容为主，风险低 |
| **22 期产能（人力和时间）** | 中 | EP.01 样片先测单期全流程耗时，据此规划批量节奏 |
