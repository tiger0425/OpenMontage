# Auto-Dub 翻译质量与节奏对齐强化 实施计划

> 基于 2026-08-09 对标调研（tachidubb / KrillinAI / Pyvideotrans 等开源项目源码），针对 Auto-Dub 用户反馈的三大痛点立项改造：说话人/音色提取一致性、翻译准确率、配音与视频节奏对齐。
> 领域术语见 `CONTEXT.md`「Auto-Dub 领域上下文」；上一轮迭代成果见 `.sisyphus/plans/auto-dub-utterance-alignment-multispeaker.md`。

## 摘要

对 Auto-Dub 批量管线做三项耦合改造，全部沿用现有 `bin/auto_dub.py` 轻/重任务解耦协议（`process` 轻任务 + Worker 跑 `render-assets` / `run-heavy`）：

1. **分段与音色一致性**：说话人分离后做分段清理（合并续句、吸收微段、拆超长段），声纹参考从「单段最长」改为「多段择优拼接」（30s 目标，1.5–12s 甜点段优先），并对克隆合成固定种子。
2. **翻译准确率**：翻译注入前文上下文（最近已译 4 条，600 字符预算）、域术语表按触发词注入、漏译/未翻译行脚本检测 + 单独重译；可编辑用户术语表。
3. **节奏对齐**：变速上限内先逐句 atempo，超限时「允许轻微溢出推挤」而非全局硬调速；音频比视频短时补静音、比视频长时冻结末帧延展；全局调速仅作末段兜底。

## 背景

### 用户反馈的三大痛点（tt-test 真机）

- **提取一致性不好**：pyannote 3 真人常被切成 4 cluster；有声纹参考短句男声克隆不稳（IndexTTS2 短句 339Hz 女声 vs 长句 127Hz 男声）；需要音高锚定兜底。
- **翻译准确率不够**：实测残留 u7 漏译"发生过性关系"、u14 "四个"应为"四次"、u18 "birds" 俚语误译"鸟"；人名音译虽已全片一致但仍有边界漏网。
- **合成后节奏不对**：tt-test 最终漂移 3.07s 靠全局 atempo 1.037（≈3.7% 加速）吸收，全局调速是末段兜底而非主动手段。

### 对标项目的解法（2026-08-09 源码调研）

| 痛点 | tachidubb | Pyvideotrans | KrillinAI |
|------|-----------|--------------|-----------|
| 分段一致性 | `segment_post.py`：合并续句（同说话人+间隙<0.5s+未句末）+ 吸收微段（<1s/<40字）+ 拆超长段（>15s） | — | LLM 智能分段对齐 |
| 音色一致性 | 全局 `voice_seed` + `cudnn.deterministic=True`；克隆模式禁 seed 变异重试（失败降 tier 不换 seed） | — | CosyVoice 音色克隆 |
| 翻译质量 | 前文上下文（600 字符预算）+ 域术语表（按触发词注入）+ 脚本检测漏译重试 | 30+ 后端 + `textmatching.py` + `fix_punc` | 术语替换 + LLM 上下文翻译 |
| 节奏对齐 | atempo 上限 1.15x + 溢出推挤（`current_end`）+ 音频比视频长用 `tpad` 冻帧 | `SpeedRate`：区间扩展（结束点=下条开始点）+ 补静音 + 视频 setpts 慢放 | — |

## 目标

1. 多人视频分音色可稳定区分，声纹参考拼接后短句克隆稳定，男声不再需要事后音高锚定兜底。
2. 翻译准确率提升：漏译/未翻译检测到并重译；域术语表命中率提升；人名/专名全片一致。
3. 配音与视频节奏：逐句对齐优先，全局调速退为末段兜底；漂移 ≤5s 目标不变，但达标路径不再依赖全局 atempo 加速。
4. 全程本地、免费，IndexTTS2 服务端零改动，单人视频零回归。

## 范围

### 做
- `apps/auto-dub/batch/pipeline_automator.py`：
  - 新增分段清理链（合并续句/吸收微段/拆超长段），应用在 diarization 输出后、原句合并前。
  - 重写声纹参考提取：按 speaker 多段择优拼接（甜点段 1.5–12s → 短段补足 → 长段截断），替代单段最长。
  - 翻译：`_translate_utterances` / `_translate_blocks` 注入前文上下文与域术语表；新增漏译检测 + 单条重译。
  - 对齐：`_build_block_audio` 溢出推挤 + 音频比视频长时 `tpad` 冻帧；`_run_compose_stage` 全局调速退为兜底。
- `apps/auto-dub/config.yaml`：新增 `segments`（合并/微段/超长参数）、`voice_ref`（拼接目标 30s、甜点段上下限）、`translation`（前文上下文预算、术语表路径、漏译检测开关）。
- 可编辑用户术语表文件（如 `apps/auto-dub/user_glossary.json`），按域触发词注入翻译 prompt。
- 新增/更新单测：`tests/auto_dub/`。

### 不做
- 不改 `D:/index-tts/indextts_server.py`。
- 不引入 seed 变异重试（IndexTTS2 服务端为黑盒，重试仍用同 seed + 同 ref，避免音色漂移）。
- 不做视频慢放（`setpts`）路线——Auto-Dub 是「以原视频为准、让配音贴合」，不是「以配音为准、改视频」。
- 不做画面字幕驱动（`subtitle_driven` 已定为死路）。
- 已处理/已发布旧成品不重跑。

## 技术决策

| # | 决策项 | 结论 | 理由 |
|---|--------|------|------|
| 1 | 分段清理时机 | diarization 输出后、原句合并前，链式 `merge_continuation → absorb_micro → split_long` | 与 tachidubb `segment_post.py` 同构；吸收微段直接治「3 人切 4 cluster」 |
| 2 | 声纹参考 | 多段择优拼接至 ~30s（甜点 1.5–12s → 短段 0.4–1.5s → 长段截 15s），peak 归一化 0.9 | 更长更干净的 ref → IndexTTS2 克隆更稳，替代音高锚定 |
| 3 | 音色确定性 | 同 seed + 同 ref 重试；合成失败换 tier/跳过，绝不换 seed | IndexTTS2 服务端黑盒，无法保证 `cudnn.deterministic`，只能同参数重试 |
| 4 | 翻译前文上下文 | 最近 4 条已译（src+tgt），600 字符预算 | 保人名/代词/时态一致（tachidubb 实证有效） |
| 5 | 域术语表 | config 内置 + `user_glossary.json` 可编辑；按触发词注入本批相关词条 | 治俚语误译（birds→俚语义）与专业词汇漂移 |
| 6 | 漏译检测 | 中文占比脚本检测 + 未翻译行单条重译；失败链 批量→单条→保留原文 | 治 u7 漏译、u14 数字错 |
| 7 | 节奏溢出策略 | 变速不可达且非 inherently_long：允许溢出推挤（下一段起点让位）| 重叠轻微优于强变速（tachidubb 实测） |
| 8 | 音画长短差 | 音频<视频补静音；音频>视频 `tpad` 冻末帧延展 | Pyvideotrans `merge_audio_video` 同构 |
| 9 | 全局调速定位 | 保留 `interview.atempo` 但只作末段兜底；优先逐句对齐吸收漂移 | 响应「合成后节奏不对」反馈 |
| 10 | 术语表优先级 | 用户术语表 > 内置术语表 > 保留英文（glossary.keep_english） | 与 tachidubb 一致 |

## 验证策略

1. **单测**：分段清理链——合并续句/吸收微段/拆超长段分别覆盖正反例。
2. **单测**：声纹拼接——甜点段优先、短段补足、长段截断；单说话人返回单 ref。
3. **单测**：漏译检测——英文残留/中文占比判定，触发单条重译。
4. **单测**：溢出推挤——连续长句累积不产生负间隔；`tpad` 分支。
5. **TikTok 实测**（tt-test 复跑）：`process` 轻任务核对分段清理后 speaker 标签；`render-assets`（派发 Compute Worker）核对多音色稳定、逐句对齐指标。
6. **回归**：单说话人视频与改造前一致；`pytest tests/`（已有基线失败除外，勿修）。

## 风险与约束

| 风险 | 影响 | 缓解 |
|------|------|------|
| 前文上下文撑爆上下文窗口 | 翻译超时/乱序 | 600 字符预算 + 失败重试时去掉前文上下文 |
| 用户术语表维护成本 | 术语覆盖不足 | 内置词表兜底；增量维护 |
| 溢出推挤改变字幕时间 | 字幕与画面错位 | 只推挤语音放置起点，SRT 时间以实际放置为准重排 |
| IndexTTS2 黑盒无法保证确定性 | 短句音色仍不稳 | 同 seed + 同 ref 重试 + 更长拼接 ref；音高锚定保留为最后兜底 |
| 分段清理合并过粗/过细 | 语义割裂 | 参数可配；tt-test 回归校准 |
| 全局调速兜底化后漂移反弹 | 长访谈视频仍可能 >5s | 逐句对齐为主 + 溢出推挤；`max_drift_seconds` 保持 5.0 作失败阈值 |

## 成功标准

1. tt-test 复跑：多音色可稳定区分，男声短句不再需要音高锚定即可保持男声。
2. 翻译准确率：u7/u14/u18 三类问题在复跑中不再出现；漏译检测拦截未翻译行。
3. 节奏：最终漂移 ≤5s 目标不变，但全局 atempo 幅度不高于逐句对齐贡献。
4. 单人视频零回归；`pytest tests/` 无新增失败。
5. IndexTTS2 服务端零改动。
